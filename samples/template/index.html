Template · 상세페이지 자동화

상품 JSON 하나 + 사진 9장
상세페이지 한 벌을 찍어냅니다

새 과일이 들어와도 디자인을 다시 만들지 않습니다. product.example.json을 복사해 값만 바꾸고 실행하면 밝은 톤 · 큰 모바일 타이포 · GIF 3종 · 1720px/860px 3분할까지 한 번에 나옵니다. 이 템플릿으로 만든 실제 결과가 v6 제주감귤입니다.

폭 860px / 1720px 본문 24~25px 움직이는 GIF 3종 Python 3.9+ 무료 폰트 4종 동봉
이 템플릿으로 만든 v6 상세페이지 보기 → 실제 파일 4개 보기
01

만들어지는 순서

스크립트 하나가 아래 5단계를 차례로 실행하고, 마지막에 제작 노트까지 씁니다. 사람이 하는 일은 ①의 JSON 고치기뿐입니다.

INPUT

① 데이터 · 사진

상품 JSON 1개와 사진 6~10장(이름 고정). 사진 폴더는 images_dir로 지정합니다.

product.json · assets/
STEP 2

② HTML 생성

18개 섹션(히어로·숫자·POINT 3개·배송·사이즈·보관·FAQ·CS·클로징)을 조립합니다.

work/source.html
STEP 3

③ 폰트 서브셋

HTML에 실제로 쓰인 글자만 잘라 woff2로 만듭니다. 폰트 4종 합계 512KB.

fonts/*.woff2
STEP 4

④ GIF 3종

혜택·까기/착즙·체크 3종을 Pillow로 프레임을 직접 그려 렌더합니다.

gif_0*.gif
STEP 5

⑤ PNG 렌더 · 분할

WeasyPrint로 PDF를 만들고 PyMuPDF로 1720px PNG 3장 + 860px 3장 + 전체 1장으로 자릅니다.

860/*.png
out/사과/ 상세페이지_v6_상단.png · _중단.png · _하단.png ← 1720px 원본 860/상세페이지_v6_상단_860.png … ← 스마트스토어 업로드용 상세페이지_v6_사과.html ← GIF가 실제로 움직이는 원본 gif_01_benefit.gif · gif_02_peel_juice.gif · gif_03_check.gif v6_제작노트.md ← 지시 반영표 · 디자인 근거 자동 정리
02

쓰는 법 3단계

준비물: Python 3.9+ · weasyprint pymupdf pillow fonttools numpy

pip install weasyprint pymupdf pillow fonttools numpy
WeasyPrint가 PDF를 만들고 PyMuPDF가 PNG로 굽습니다. GIF는 Pillow만 씁니다.
# ① 예시 JSON을 복사해서 값만 바꿉니다 cp product.example.json product.사과.json # ② 사진을 assets/사과/ 에 넣고 JSON의 images 값을 그 파일명으로 # ③ 실행 python3 generate_detail_page.py --data product.사과.json --out ./out/사과
옵션기본값설명
--data(필수)상품 데이터 JSON 경로
--out(필수)산출물 폴더. 없으면 만듭니다
--scale2PNG 배율. 2 = 1720px 폭, 1 = 860px(빠른 미리보기)
--no-gif꺼짐GIF 없이 빠르게 확인할 때
사진 규칙 한 줄. 사진 안에 글자·로고·워터마크를 넣지 마세요. 글자는 HTML이 그립니다. 2000px 이상 원본을 쓰면 1720px 출력에서도 선명합니다. AI 생성컷은 시안 확인용이고, 실제 판매에는 실사진을 써야 합니다.
03

실제 파일 4개

템플릿 폴더 그대로입니다. 내용을 그 자리에서 열어 볼 수 있고, 파일로 내려받아 바로 실행할 수 있습니다.

04

JSON 구조

product.example.json이 곧 스키마입니다. 값만 바꾸면 섹션 순서·디자인은 그대로 유지됩니다.

키무엇을 정하나
meta브랜드 · 상품명 · file_prefix(파일명 접두어) · product_slug · images_dir
seometa description 문구
images사진 9컷 파일명 (hero · peel · segments · juice · harvest · sorting · box · boxtop · size)
emoji_codes트위모지 코드 (과일 아이콘)
topbar최상단 띠 문구 좌/우
hero대표컷 · 한 줄 약속 · 손글씨 문구 · 가격 3칸 · 후킹 제목 3줄
trust신뢰바 4개 (아이콘 이름 + 제목 + 설명)
gifGIF 3종의 문구·숫자·컷. enabled:false면 GIF 없이 생성
specs"숫자로 보는 한 상자" 카드 4개 + 각주
statement왜 이 상품인가 · 비교표 · 맞음/안 맞음
pointsPOINT 01~03 (제목 · 본문 · CHECK · 사진 · 스티커)
shipping배송 4단계 타임라인 + 상자 단면도 + 파손 보상
size지름 숫자 · 구성 카드 · 100g당 가격 바 · 스펙표
options2.5kg / 4.5kg 옵션 카드와 각주
storage보관 4단계 + 온도 카드
faqQ/A 5개 (답변에 <b> 사용 가능)
cs출고 · 배송 · 수령 후 확인 · 교환/환불 4칸
closing마지막 CTA + 가격 배지 3개
footer사업자 정보 (상호 · 대표 · 사업자번호 · 통신판매업 · 주소)

06

산출물과 업로드 규칙

스마트스토어에는 860/ 3장을 순서대로 올립니다. 각 5,000px 이하 권장.

out/제주감귤/ ├─ 상세페이지_v6_상단.png / _중단.png / _하단.png 1720px 원본 · 7.8 / 5.9 / 0.8MB ├─ 상세페이지_v6_전체.png 860px 1장 · 확인용 · 16,635px ├─ 860/상세페이지_v6_상단_860.png … 6,293 / 6,274 / 4,068px · 2.4 / 1.8 / 0.8MB ├─ 상세페이지_v6_제주감귤.html GIF가 실제로 움직이는 원본 (70KB) ├─ gif_01_benefit.gif 860×300 · 54프레임 · 0.7MB ├─ gif_02_peel_juice.gif 860×600 · 30프레임 · 5.3MB ├─ gif_03_check.gif 860×300 · 40프레임 · 0.6MB ├─ v6_제작노트.md 지시 반영표 · 리서치 근거 ├─ assets/ · fonts/ HTML이 참조하는 사진·폰트 └─ work/source.html · page.pdf 중간 산출물
왜 3분할인가. 네이버 스마트스토어 상세는 이미지를 세로로 이어 붙여 올리는 구조라, 5,000px 이하로 잘라야 깨지지 않습니다. 분할 지점은 HTML의 .mark-mid · .mark-bot 자리에서 자동으로 계산합니다.

08

자주 나는 문제

증상원인 / 해결
한글이 어절 중간에서 끊김스크립트의 keepall()이 음절 사이에 WORD JOINER를 넣어 처리합니다. HTML을 직접 고칠 때도 이 함수를 거치세요.
페이지가 잘림@page size가 40,000px입니다. 아주 긴 상품이면 build_css()의 값을 키우고 렌더 로그의 "페이지가 N장" 경고를 확인하세요.
GIF가 안 생김assets/에 peel·segments·juice 사진이 있는지 확인. 없으면 GIF 02만 건너뜁니다.
글자가 네모(□)로폰트 서브셋 문자셋에 없는 글자입니다. JSON에 새 글자를 넣으면 자동으로 다시 서브셋됩니다.
파일이 너무 큼--scale 1로 미리보기 후 최종만 --scale 2. GIF 02는 5MB 안팎입니다.
